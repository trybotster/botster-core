## F12 — HIGH — Independent cleanup can end before the payload

Status: OPEN. The package reviewer owns this finding.
The integration reviewer independently confirmed the source path.

Evidence at the reviewed head:

- `crates/botster-core-sys/tests/common/payload_guard.rs:92-109` registers a handler only for SIGHUP.
- `crates/botster-worker/tests/slow_session.rs:290-303,356-369` sends group SIGTERM to a payload that ignores TERM.
- The guard starts before the shell installs its TERM trap. The guard therefore retains SIGTERM's default action.

Group SIGTERM ends the guard while the payload remains alive.
If worker cleanup then becomes unavailable, guard Drop closes a socket whose guard member is already dead.
The surviving payload group has no independent cleanup owner.
The new panic test sends no graceful group signal before worker SIGKILL, so that test does not cover this path.

Required change: Keep independent cleanup available after the graceful group signal.
Preserve current-group ownership and production-only payload reaping.
Add proof that sends the graceful signal, makes worker cleanup unavailable, and then triggers test panic.
The proof must show that the guard ends the surviving payload group.

Authority: BUILD.md testing rule 10 and plan risk R12.
Closure requires a new exact-head package verdict and an integration delta review.
