# Docs

## Living truth

- **`architecture/`** — current system design, contracts, and ADRs. Read these first.
- Root `README.md` — product/API overview for embedders and contributors.
- **`examples/`** — package manifest shape examples used by contract tests.

## Historical archive

- **`archive/plans/`** — landed implementation plans. Useful for archaeology; not active intent and not the source of truth for how the system works today.

When a plan graduates, its durable decisions belong in `architecture/` (or the root README). The plan itself stays in the archive as historical sludge.
