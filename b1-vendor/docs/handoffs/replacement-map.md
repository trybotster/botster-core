## How the map is made
The JSON is generated by scratch scripts, NOT in the repo: `~/botster-sessions/shared/foundation/scratch-replacement-map/` (`classify.py` holds all rules and per-id sets, `gen.py` writes the JSON, `show.py`/`clause.py` print clause text, `text.json` is the extracted clause text). Run from the worktree: `python3 .../gen.py`, then `botsterq run --label replacement-map --deadline 10m -- cargo xtask replacement-map`. Editing the JSON by hand also works; `--check` validates it.

## Gotchas
- zsh does not word-split `$c` in loops: pass xtask args explicitly to `botsterq run`.
- Never pipe a gate before `&&` (memory: gate commands never piped). Run unpiped; use pipefail.
- New ledger ids from main break `--check` until mapped (by design). After any merge of main, run `cargo xtask ledger --check` then `replacement-map --check`.
- Keep scratch out of the repo; no /private/tmp for shared state.
