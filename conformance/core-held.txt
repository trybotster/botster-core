# Each line: the id, the reason class, the owner, the authority, and the reason. Two classes:
# - `budget`: the id passes, but over the default-tier time budget. It runs at the first seed only.
# - `unproven`: the id passes on the testkit, but that pass does not prove the clause; the line names the missing proofs.
#   It runs at every seed. Its line leaves this file in the PR that adds the last missing proof, which also flips the id.
# A real-only id needs no line here: core-real-only.txt comes from the replacement map.
# A held id must pass: when it fails, the strict run fails until its line is removed (the id stays pending).
# A `budget` id runs at the first seed only, so its line states that its full-seed proof is missing, and why.
# This list must not grow: a second `budget` line, and every new `unproven` line, goes to the Core lead first (lead, 2026-10-09).
